## Vocabulary
Interpreter - as opposed to a compiler, an interpreter does not first take instructions and translate them into binary code for execution by the processor. instead the interpreter scans the code and executes it directly rather than producing a standalone executable
Executable - a program the operating system knows how to start
Process - a running instance of a program
RAM - Random Access Memory; short term, fast storage the computer uses for caching and accessing data from a hard disk or other source. when a program is loaded, data that is needed quickly is loaded into RAM for easy retrieval and modification. currently running programs and their data live in RAM
Disk - in a modern sense often not a disk but refers to long-term storage.  name is a holdover from  when everything was kept on magnetic disks
Model - i presume in the context of this learning, this refers to the AI programs that have been trained by different people or companies.  the model is the released data (weights) that has already been through pre- mid- and post-training (or whatever convention comes later) and is available to run either locally or via cloud, depending on the distribution strategy. important distinction - a model can be conceptualized as specific data that can be interpreted by software to execute tasks, the model itself is not software so much as data
Runtime - assume this refers to a runtime environment, a sort of supporting middle layer in the software that enables the code to run by managing the various aspects of running software on the computer e.g. I/O, RAM use, etc.  simplification from ChatGPT - a runtime is the environment that exists while a program is running

### ChatGPT refinement
modern LLMs don't iterate by letter prediction, but by token prediction and generation.  tokens can be thought of as characters, syllables, words or pieces of words, and each tokenizer breaks the language down into these tokens in its own way.

ollama example:
"text input to ollama" -> ollama receives text -> tokenizer converts into numbers -> model loads numbers into memory -> billions of matrix multiplications happen -> model predicts most likely next token -> new token gets appended -> entire conversation including the new token is fed back into the model -> repeat until the model predicts it is finished

my reference to internal drafting is somewhat accurate of reasoning models which weigh generated solutions before generating an answer, but could not be considered a "general" feature.

### Three dots
why is "." chosen to mean "here"?

i think it's a super common command to need, and if "." is "here" then ".." as "up a level" is intuitive and similarly shorthand as this type of navigation would be necessary.  i'm not sure if a period being also a point is intentional to conceptualize "here", but at least for me it's helpful as well.

the actual reason has to do with historical development of computer systems.  on unix systems, every directory contains two special directory entries:
- "." points to the current directory
- ".." points to its parent

modern OS preserve the convention
