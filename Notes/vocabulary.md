# Vocab terms
add here as terms are introduced for notation and easy reference

## Interpreter
- as opposed to a compiler, an interpreter does not first take instructions and translate them into binary code for execution by the processor. instead the interpreter scans the code and executes it directly rather than producing a standalone executable

## Executable
- a program the operating system knows how to start

## Process
- a running instance of a program

## RAM
- Random Access Memory; short term, fast storage the computer uses for caching and accessing data from a hard disk or other source. when a program is loaded, data that is needed quickly is loaded into RAM for easy retrieval and modification. currently running programs and their data live in RAM

## Disk
- in a modern sense often not a disk but refers to long-term storage.  name is a holdover from  when everything was kept on magnetic disks

## Model
- i presume in the context of this learning, this refers to the AI programs that have been trained by different people or companies.  the model is the released data (weights) that has already been through pre- mid- and post-training (or whatever convention comes later) and is available to run either locally or via cloud, depending on the distribution strategy. important distinction - a model can be conceptualized as specific data that can be interpreted by software to execute tasks, the model itself is not software so much as data

## Runtime
- i assume this refers to a runtime environment, a sort of supporting middle layer in the software that enables the code to run by managing the various aspects of running software on the computer e.g. I/O, RAM use, etc.  simplification from ChatGPT - a runtime is the environment that exists while a program is running

## Variable
A named place to store information while the program is running

## String
Text

## Function
A named action that performs some work

## Decoupling
Reducing unnecessary dependencies between components.
